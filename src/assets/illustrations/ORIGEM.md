# Origem das imagens

As ilustrações do MarkTech foram desenhadas para este site. Os arquivos SVG nesta pasta são a origem. O script `scripts/render-images.mjs` gera PNG e WebP a partir deles.

Não há foto de banco de imagens, print de celular de terceiros, logotipo do WhatsApp, da Meta, do Google, da Samsung, da Motorola ou da Xiaomi.

Paleta usada nas artes: papel `#efe6d8`, tinta `#1b2740` e cobre `#c56a32`. O verde de identidade do WhatsApp não entra nesses arquivos.

Uso: as imagens acompanham o site MarkTech. Não são um pacote de ícones para redistribuir separado dos tutoriais.
